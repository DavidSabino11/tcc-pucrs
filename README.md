# TCC - PUCRS (Pós-Graduação Full Stack)

Este repositório reúne os principais projetos desenvolvidos durante a formação em Desenvolvimento Full Stack da PUCRS, com foco em prática, integração de tecnologias e fundamentos de programação.

## Estrutura de Projetos

- **fundamentos-algoritmos**: Algoritmos básicos com JavaScript (funções, conjuntos, listas encadeadas, BST).
- **poo-js**: Projeto de POO com JavaScript, simulando uma locadora de veículos.
- **devops**: Exemplo de CI com GitHub Actions e Docker.
- **programacao-web**: Página interativa com manipulação do DOM usando HTML, CSS e JS.
- **arquitetura-client-side**
  - *react-fundamentos*: Exemplos com useState, useEffect, forms e eventos.
  - *aplicacao-next*: Projeto básico com Next.js e TailwindCSS.
- **arquitetura-server-side**
  - *exemplo-server*: CRUD em memória com Express (padrão MVC).
  - *cartoes*: Gerenciador de cartões com Express e estrutura modular.
- **xp-tdd**: Simulação de parquímetro com TDD e Jest.
- **integracao-rest-soap**: API REST + consumo de serviço SOAP.
- **qualidade-testes**: Validação de produto com testes unitários e de integração.
- **bd-relacional**: Sistema de biblioteca com SQL (DDL + DML + consultas).
- **bd-nosql**: CRUD com MongoDB e Redis (cache).

## Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/DavidSabino11/tcc-pucrs.git
```

2. Acesse a pasta de cada projeto e siga as instruções locais de instalação e execução (normalmente `npm install` e `npm start` para projetos Node.js).
